# 问题一：孕妇外周血Y染色体浓度影响因素探究

---

## 摘要

本研究的核心目标是构建一个稳健的数学模型，以识别并量化影响孕妇外周血中胎儿Y染色体浓度的关键生理指标。研究工作基于一个包含孕妇年龄、孕周（GA）、体重指数（BMI）及其他临床特征的多维度数据集展开。在初始的探索性数据分析阶段，我们通过可视化方法发现，目标变量与各解释变量间的关系并非简单的线性模式，这为模型选择提供了关键的初步依据。

在建模路径上，我们首先评估了作为基准的普通最小二乘法（OLS）线性模型的适用性。然而，对该模型的诊断检验揭示出其残差与关键自变量间存在明显的非线性结构，证明纯线性假设无法充分捕捉数据中的复杂规律。基于此，我们最终选择了具备更高灵活性的广义可加模型（GAM）进行深入分析。为提升模型的稳健性与泛化能力，我们对部分呈现偏态分布的变量（Y染色体浓度、BMI、年龄）进行了对数变换，并借助严谨的10折交叉验证方法对模型平滑项的惩罚系数进行了优化。

最终确立的GAM模型在解释数据变异方面表现出色，其伪R平方达到0.2272，显著优于基准OLS模型。更重要的是，模型成功揭示了检测孕周、孕妇BMI及年龄对Y染色体浓度存在显著的、非线性的复杂影响模式。为验证模型的可靠性，我们进行了一系列严格的统计诊断（如同方差性与正态性检验），并通过在一个全新的、未参与训练的测试数据集上的成功应用，证实了模型的有效性和良好的泛化能力。

---

## 1. 模型的建立

### 1.1 背景、目标与建模思路

孕妇外周血中存在的胎儿游离DNA（cell-free fetal DNA, cffDNA）为无创产前检测（NIPT）提供了可能。其中，Y染色体浓度是评估怀有男性胎儿的孕妇cffDNA含量的一个重要指标。然而，该浓度在不同个体间差异显著，准确识别其背后的影响因素，对于优化检测流程、提高诊断准确性具有重要的临床应用价值。本研究的核心任务，正是从一系列复杂的生理指标中，筛选出关键影响因素，并构建一个能够准确、可解释地描述其内在关系的数学模型。

我们的建模策略遵循由简入繁、层层递进的原则：
1.  **数据探索先行**：通过系统性的探索性数据分析（EDA），理解各变量的统计分布特性与两两之间的初步关系，为模型选择提供实证依据。
2.  **建立线性基准**：首先构建一个标准的普通最小二乘法（OLS）模型，作为后续复杂模型的性能参照基准。
3.  **诊断与迭代**：严格评估基准模型的充分性。若模型诊断暴露其局限性（如非线性残差），则选择更高级的模型（如广义可加模型GAM）进行迭代优化。
4.  **验证与确认**：通过交叉验证、残差分析和外部数据集测试，确保最终模型的稳健性、可靠性与泛化能力。

### 1.2 数据探索：揭示非线性关系的必要性

在正式建模前，对数据的初步探索是识别数据特性、指导模型选择的关键环节。

- **变量分布特征**：我们首先考察了核心变量的分布形态。如下图所示，目标变量“Y染色体浓度”以及关键自变量“孕妇BMI”均呈现明显的右偏分布，大量观测值集中在较低区域，并伴有长尾。这种偏态分布违背了经典线性回归模型对残差正态性的假设，直接建模可能导致参数估计的偏误和效率损失。这提示我们，在建模时采用对数变换等方式处理偏态是必要的预处理步骤。

- **线性相关性分析**：为了解变量间的线性关联强度，我们计算了皮尔逊相关系数矩阵并将其可视化为热力图。结果显示，各生理指标与Y染色体浓度之间的线性关系普遍不强，相关系数的绝对值大多低于0.3。这一现象强烈暗示，变量之间可能隐藏着更为复杂的非线性关系，仅仅依赖线性模型很可能会错失关键信息。

基于以上观察，我们确认了单纯的线性模型可能不足以胜任本任务。但为了建立一个清晰的比较基准，我们仍从OLS模型开始分析。

### 1.3 基准模型：普通最小二乘法（OLS）的局限性

我们首先构建了一个多元OLS线性回归模型作为分析的基点。为了缓解数据的偏态问题，我们对Y染色体浓度、孕妇BMI和年龄变量进行了对数变换。模型形式如下：
`log(Y_concentration) ~ log_Age + log_BMI + GA_days + ...`

然而，对该基准模型的诊断分析暴露了其内在的结构性缺陷。模型的残差（即预测值与真实值之差）包含了所有未能被模型捕捉的系统性信息。如果一个模型是充分的，其残差应当表现为围绕零点随机波动的白噪声。但下图清晰地显示，OLS模型的残差与“检测孕周”及“对数年龄”之间，存在明显的、非随机的曲线模式。

![OLS模型残差图](./model_comparison_plots/ols_residual_plots.png)

具体而言，残差与孕周的关系呈现一个倒U型，表明OLS模型在孕期的早、晚阶段系统性地低估了Y染色体浓度，而在孕中期则系统性地高估了它。这种系统性的预测偏差是一个强有力的信号，证明数据中存在OLS线性模型无法有效拟合的非线性结构。因此，我们必须放弃纯线性假设，转而寻求能够灵活处理非线性关系的更高级模型。

### 1.4 进阶模型：广义可加模型（GAM）的选择与构建

为了精确捕捉并量化这种非线性关系，我们引入了广义可加模型（GAM）。GAM是线性模型的自然推广，其核心优势在于，它不对变量与因变量间的关系做严格的线性假设，而是通过数据驱动的、灵活的平滑函数（splines）来拟合。这种方法通过将每个变量的效应表示为基函数的加权和，使得模型能够学习复杂的数据模式，而这正是OLS模型所缺失的能力。其基本形式可以表达为：

$$ g(E[Y]) = \beta_0 + s_1(x_1) + s_2(x_2) + ... + s_p(x_p) $$

此处的 $s_i(x_i)$ 代表了模型为第 $i$ 个自变量 $x_i$ 找到的最优平滑函数。这种“可加”的结构使得GAM在具备高度灵活性的同时，依然保持了良好的可解释性——每个变量对结果的边际效应可以被独立地进行可视化和分析。

结合数据探索的发现和OLS模型的不足，我们最终确立的GAM模型结构如下：

`log(Y_concentration) ~ s(GA_days) + s(log_BMI) + s(log_Age)`

其中，`s()`代表对该变量进行平滑函数拟合。我们选择这三个变量进入最终模型，是基于OLS残差分析所揭示的、它们与目标变量间最强的非线性信号。

## 2. 模型的求解

模型的求解过程，核心在于如何为每个平滑项找到最优的“平滑度”，以在精确拟合数据和避免过拟合之间取得最佳平衡。

### 2.1 求解方法：惩罚样条回归

我们采用带有惩罚项的样条回归（Penalized Splines）来估计每个平滑函数。该方法在模型的损失函数中加入了一个惩罚项，该惩罚项的大小与函数的“弯曲度”（通常用其二阶导数的积分来衡量）成正比。这个惩罚的强度由一个关键的超参数——平滑惩罚系数 `lambda (λ)` 控制。

-   `lambda` 越大，对“弯曲”的惩罚越重，拟合出的曲线就越平滑，在极限情况下会退化为一条直线（即回到线性模型）。
-   `lambda` 越小，对“弯曲”的惩罚越轻，拟合出的曲线就越灵活，能更好地追踪数据点，但有过拟合数据中噪声的风险。

因此，科学地选择`lambda`值，是GAM模型求解成败的关键。

### 2.2 最优参数选择：10折交叉验证

为了客观、科学地确定每个平滑项最优的 `lambda` 值，我们采用了计算上更密集但结果更可靠的 **10折交叉验证（10-fold Cross-Validation）** 方法。具体流程如下：

1.  **数据划分**：将原始数据集随机、均匀地划分为10个大小相近的互斥子集。
2.  **循环训练与验证**：进行10轮迭代。在每一轮中，取其中9个子集作为训练集来训练模型，剩下的1个子集作为验证集。
3.  **误差评估**：在验证集上计算模型的预测误差（如均方误差）。
4.  **参数寻优**：对一系列候选的 `lambda` 值重复步骤2和3，记录每个`lambda`值在10轮验证中的平均预测误差。
5.  **确定最优参数**：最终，选择那个使得10折交叉验证平均误差最小的 `lambda` 值，作为该平滑项的最佳惩罚系数。

通过这一严谨的、数据驱动的流程，我们为模型中的每一个平滑项都找到了最优的正则化强度，从而最大限度地保证了模型在新数据上的泛化能力。

![10折交叉验证流程图](./Question1/cross_validation_flowchart.png)

### 2.3 求解结果

经过交叉验证优化后的GAM模型，其求解结果的关键性能指标如下：

-   **伪R平方 (Pseudo R-Squared)**: **0.2272**。该值衡量了模型能够解释的Y染色体浓度（对数变换后）方差的比例。它远高于基准OLS模型约0.1的R平方，说明GAM的非线性结构额外解释了数据中约12.7%的变异。这是一个在实际应用中非常显著的提升，证明了引入非线性项的必要性和有效性。
-   **平滑项显著性**: 模型中包含的所有三个平滑项（`s(GA_days)`, `s(log_BMI)`, `s(log_Age)`）的P值均远小于0.001。这提供了强有力的统计学证据，使我们能够拒绝“这些变量对Y染色体浓度没有影响”的原假设，并确认它们各自的非线性影响是真实存在的，而非随机波动。

完整的模型摘要信息可见附录，其中包含了各平滑项的有效自由度（Effective Degrees of Freedom, EDF）等更多技术细节。

## 3. 模型的分析

在确立并求解了模型之后，我们进入了模型分析阶段。这一阶段的目标是：深入解读模型所揭示的变量间关系，并全面验证模型的可靠性与稳健性。

### 3.1 模型解读：变量如何非线性地影响Y染色体浓度？

偏依赖图（Partial Dependence Plots, PDP）是解读GAM模型中非线性效应的有力工具。它能够将每个自变量对预测结果的边际效应独立地可视化出来，即在控制其他变量不变的情况下，展示单个变量变化时，Y染色体浓度的预测值如何变化。

![最终GAM模型的偏依赖图](./gam_model_plots_cv/gam_partial_dependence_plots_cv.png)

上图揭示了各个关键因素与Y染色体浓度之间具体、复杂的非线性关系：

1.  **检测孕周 (GA_days)**：Y染色体浓度并非随孕周单调递增。在孕早期，浓度存在一个快速的上升期，这与胎盘血管化和细胞交换活动日益频繁的生理过程相符。但在大约150天（约21周）后，这种增长趋势明显放缓，进入一个平台期。这说明孕周对浓度的边际效应是递减的，在孕晚期，单纯孕周的增加对浓度的贡献已非常有限。

2.  **对数BMI (log_BMI)**：BMI的影响呈现出一种非线性的“U型”关系，这一点尤为值得关注。当孕妇的BMI处于正常范围的中等水平时，Y染色体浓度反而处于一个相对较低的水平。而对于体重偏瘦或超重、肥胖的孕妇，其浓度有更高的趋势。这可能暗示，偏离理想体重的状态（无论是过低或过高）可能伴随着某些生理应激或代谢变化，这些变化可能通过影响胎盘功能或母体血液稀释效应，间接导致了Y染色体浓度的相对升高。

3.  **对数年龄 (log_Age)**：年龄的影响同样不是线性的，而是呈现一种“倒U型”模式。数据显示，Y染色体浓度在较年轻的孕妇中相对较低，随后随年龄增长而提升，但在30-35岁年龄段达到一个峰值后，便开始呈现下降的趋势。这种模式可能反映了不同年龄段女性生理机能的综合差异，但其背后的确切生物学机制仍需进一步研究。

### 3.2 模型可靠性验证

一个模型的结论是否可信，取决于其本身是否满足基本的统计假设。我们通过一系列诊断检验来评估模型的“健康状况”。

-   **残差随机性与同方差性检验**：我们绘制了模型的皮尔逊残差与模型拟合值的散点图。图中散点均匀、随机地分布在水平线0的两侧，未形成“喇叭口”（异方差）或曲线（非线性不足）等系统性结构。这说明模型的误差项具有恒定的方差，满足同方差性的基本假设，且模型已经充分捕捉了数据中的非线性关系。

    ![残差 vs. 拟合值](./gam_diagnostic_plots/residuals_vs_fitted.png)

-   **残差正态性检验**：通过正态Q-Q图，我们评估了模型残差是否服从正态分布。图中，代表残差分位数的散点能够很好地贴合在代表理论正态分布的对角线上，尤其是在中心区域。这证明模型的残差分布近似于正态分布，这是许多统计推断（如参数的置信区间计算）有效性的基础。

    ![残差的正态Q-Q图](./gam_diagnostic_plots/qq_plot.png)

综合各项诊断结果，我们构建的GAM模型表现稳健，其残差满足了模型的基本统计假设。这为我们从模型中得出的科学结论提供了坚实的统计学支持。

### 3.3 模型泛化能力测试：在新数据集上的表现

为了最终确认模型的泛化能力——即其在未见过的新数据上的表现——我们将其应用到一个全新的、未参与任何训练过程的测试数据集 `newtest.xlsx` 上。这一步骤是检验模型是否过拟合的关键。

![模型在新数据上的预测对比](./Question1/model_comparison_plots/fitted_vs_actuals_comparison_newtest.png)

如上图所示，该图对比了GAM（绿色）和OLS（橙色）模型在新数据上的预测值与真实值的关系。结果再次印证了我们的选择：
-   GAM的预测值（绿色散点）依然比OLS的预测值（橙色散点）更紧密地围绕在代表“完美预测”的45度对角线周围，表现出更低地预测误差和更强地预测一致性。
-   与此同时，OLS模型在新数据上的残差图（未单独展示，但其散点分布规律与上图一致）依然暴露了其无法处理非线性关系的根本缺陷。

这一系列在“新样本”上的测试，证明了我们的GAM模型学习到的是数据中普遍、真实的潜在规律，而非仅仅记住了训练数据中的随机噪声，因此具有很强的泛化能力和实际应用价值。

此外，我们还针对新数据集生成了包含所有数值变量的相关性热力图，进一步确认了检测孕周（GA）和孕妇BMI是影响Y染色体浓度的主要因素，而其他变量的直接线性相关性普遍较弱，再次支持了采用非线性模型的必要性。

![新数据集所有数值特征相关性热力图](./Question1/correlation_heatmap_newtest_full.png)

## 4. 结论

综合以上系统的建模、求解与分析过程，我们得出以下核心结论：

1.  **模型的选择与确立**：通过对线性和非线性模型的系统比较与诊断，我们证明了广义可加模型（GAM）能够有效捕捉影响Y染色体浓度的复杂非线性因素，其性能显著优于传统的线性模型。最终确立的交叉验证优化后的GAM模型具有良好的解释能力（伪R²=0.2272）和稳健的统计特性。

2.  **关键影响因素及其作用模式**：研究精准地确定了三个对Y染色体浓度具有显著非线性影响的关键因素，并揭示了它们各自独特的作用模式。
    -   **检测孕周**：其影响呈现“快速上升后趋于平稳”的饱和效应模式。
    -   **孕妇BMI**：其影响呈现非单调的“U型”模式，中等BMI对应相对较低的浓度。
    -   **孕妇年龄**：其影响呈现“倒U型”模式，浓度在30-35岁年龄段达到峰值后回落。

3.  **模型的可靠性与价值**：通过严格的统计诊断（残差分析）和在全新数据集上的成功验证，我们证明了所构建的GAM模型是稳健、可靠且具有良好泛化能力的。该模型不仅为理解Y染色体浓度变化的生物学机制提供了新的视角，也为未来构建更精准的临床预测工具奠定了坚实的方法学基础。
